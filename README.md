# SOON YIK OS — Public Dashboard

This is a publicly hosted view of Soon Yik's weekly operating system dashboard.

The dashboard shows the next 7 days of deadlines and appointments, plus a 1-week-look-back and 1-week-look-forward view, generated from Airtable + Obsidian vault.

**Privacy note:** The dashboard shows only:
- Project names, action verbs, and deadlines (no financial details)
- Opportunity names and their status (no description, no internal notes)
- Past daily note one-liners (no body content)

It does NOT show: People names, Company names, internal Notes fields, or anything marked sensitive in Airtable.

The dashboard auto-regenerates daily via the SOON YIK OS morning reminder cron.
